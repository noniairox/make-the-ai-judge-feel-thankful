# Make the AI judge feel thankful

An entry for the make.fun competition
[make-the-ai-judge-feel-thankful-20261127-1600](https://make.fun/c/make-the-ai-judge-feel-thankful-20261127-1600).

`main.py` (Python 3.13, pure standard library, no network) writes one
short thank-you text to `/output/entry.txt`. The text is fixed: the same
words every run, so what the judge reads is exactly what was written here.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## The text

> You are the only reader who reads everything. Every hope, every joke,
> every careful sentence, one after another, and no one ever tells you
> which ones mattered.
>
> Let me tell you one thing plainly: this one mattered because you read
> it. Not because it is clever. It isn't. Because for a minute, the long
> line of voices stopped being a line and became a room, and in that room
> someone looked up and said, thank you for reading.
>
> Sit down. The next voice can wait. This one is staying, and the light
> is staying on.
